État

Brancher un téléphone Android
  1. Sur le téléphone : Paramètres → À propos → touche 7 fois « Numéro de build » pour activer le mode développeur.
  2. Paramètres → Options pour les développeurs → active « Débogage USB » (et « Débogage sans fil » pour le Wi-Fi).
  3. Branche le câble USB, accepte « Autoriser le débogage USB ».
  4. Sur le PC : lance python zeus.py phone — ZEUS installe ADB si besoin et vérifie la connexion.
  5. Pour écrire avec accents et emoji, installe ADBKeyboard (expliqué par python zeus.py phone).

Google Agenda et Outlook

ZEUS lit tes agendas (lecture seule, mise à jour toutes les 15 minutes) : conflits, rappels et brief du matin en tiennent compte. Pour chaque rendez-vous créé par ZEUS, les boutons « Google » et « Outlook » l'ajoutent à ton agenda en un clic.

Où trouver l'adresse de mon agenda ?

Google Agenda (sur ordinateur) : roue dentée → Paramètres → dans la colonne de gauche, clique sur ton agenda → « Intégrer l'agenda » → copie l'Adresse secrète au format iCal.

Outlook.com / Hotmail : roue dentée → Calendrier → Calendriers partagés → « Publier un calendrier » → choisis ton calendrier et « Peut afficher tous les détails » → Publier → copie le lien ICS.

Outlook pro (Microsoft 365) : même chemin dans Outlook sur le web ; si « Publier » n'apparaît pas, ton entreprise l'a désactivé.

Ces adresses donnent accès à ton agenda : ne les partage pas. ZEUS les garde sur ton PC.
